Quickly share your DADAKAEV CAL meeting links with Raycast. Requires [Raycast.com](https://www.raycast.com/) to be installed and the Cal.com extension from the Raycast Store needs to be installed: https://www.raycast.com/cal/. You can create an API token in your Developer DADAKAEV CAL Settings, and then you can add the API Key by opening up the Cal.com App in Raycast.
